Features Overview

Designed for Precision & Privacy

Automatic Time Tracking

Accurately tracks active foreground window changes with second-level precision, automatically pausing when you leave your desk.

Anti-Tamper Protocol

Cryptographic Time Integrity

1

Monotonic Clock Co-Verification

Pairs standard epoch timers with hard hardware monotonic systems to identify user-side system clock manipulation or local timestamp shifting.

2

NTP Server Synchronization

Leverages low-overhead background queries to multiple online NTP platforms to verify standard UTC alignment and isolate system time discrepancies.

3

SHA-256 Hash Chain

Interlinks individual time-tracking records into an immutable cryptographic chain, guaranteeing that retroactive attempts to modify log files invalidate the integrity validation.

4

Real-Time Trust Scores

Continuously computes a system integrity rating between 0 and 100, automatically logging specific warning events and auditing potential tampering.

Quick Start Guide

Option 1: Run from Source

powershell 
# Clone repository and access directory
git clone https://github.com/yourusername/FocusLog.git
cd FocusLog

# Install application requirements
pip install PyQt6 pywin32 psutil Pillow

# Launch tracker script
run.bat

Option 2: Standalone Executable

powershell 
# Install compilation tools
pip install pyinstaller

# Run automated assembly script
build.bat

# Resulting binary is generated in the parent folder:
# .\FocusLog.exe
